# Insomniac Spiderman Movement System

https://youtu.be/MOJZPnMYroo

## Overview
A "web-swinging" mobility system entirely based off of the Insomniac Spiderman Playstation games.


There is web-swinging, web-zipping (moving linearly towards a target), instant turning, gliding, hold-to-jump-higher, wall-climbing, and upside-down walking.
